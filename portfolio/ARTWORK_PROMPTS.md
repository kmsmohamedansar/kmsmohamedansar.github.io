# Spotlight artwork prompts

The Flight Recorder and Exposure Audit covers were generated with the built-in image generation tool on 2026-10-27 and optimized as JPEGs for the portfolio. They are conceptual illustrations, not screenshots or evidence from either product.

## Agent Flight Recorder

> Use case: stylized-concept
> Asset type: square editorial cover for a portfolio project, Agent Flight Recorder.
> Primary request: Visualize an AI agent failure being traced to one earlier file edit. A central sculptural recorder made of layered translucent evidence cards and a compact dark mechanical core; three connected steps follow a crisp terracotta path from a file inspection card, to a code-change card with one small removed segment, to a failed test signal. A circular magnifying lens isolates the removed segment. The relationship should read at thumbnail size without written labels.
> Style/medium: polished tactile 3D editorial illustration, architectural model and paper sculpture; matte ivory card, smoked glass, graphite metal, fine embossed detail, subtle grain.
> Composition/framing: centered isometric arrangement, generous breathing room, strong large-scale silhouette, square crop. Fine drafting-grid lines, calibration crosses and a faint circular arc in the background, matching a premium technical portfolio series.
> Lighting/mood: soft warm studio light with restrained orange glow on the evidence path and deep charcoal shadows.
> Color palette: warm parchment beige, charcoal black, muted stone, terracotta orange, tiny coral-red failure accent.
> Constraints: No words, letters, numbers, code glyphs, logos, watermarks, people, aircraft or literal flight data. No photorealistic computer screen. Keep it distinct from a generic dashboard illustration.

## Exposure Audit

> Use case: stylized-concept
> Asset type: square editorial cover for a portfolio project, Exposure Audit.
> Primary request: Visualize a careful authorized inspection of a public website's visible surface. A central sculptural browser window built from layered ivory paper and smoked glass, inside a clearly bounded circular inspection perimeter. A narrow terracotta scanning beam examines only a few exposed surface artifacts: an abstract API document, a safely masked key-shaped token, a linked document page, and small header-policy sliders. A small physical gate at the boundary communicates authorization and limits. The inspection stays inside the perimeter; no imagery of hacking or attacking.
> Style/medium: polished tactile 3D editorial illustration, architectural model and paper sculpture; matte ivory card, smoked glass, graphite metal, fine embossed detail, subtle grain.
> Composition/framing: centered isometric arrangement, generous breathing room, strong large-scale silhouette, square crop. Fine drafting-grid lines, calibration crosses and a faint circular arc in the background, matching a premium technical portfolio series.
> Lighting/mood: soft warm studio light with restrained terracotta highlights and deep charcoal shadows.
> Color palette: warm parchment beige, charcoal black, muted stone, terracotta orange, one muted sage safe-status accent.
> Constraints: No words, letters, numbers, code glyphs, logos, watermarks, people, padlock cliché, skulls, red alarm graphics, or photorealistic computer screen. Make this visually distinct from the Flight Recorder timeline cover.
