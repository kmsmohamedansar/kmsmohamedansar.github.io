# Rules for working on Sitescout

Copied from the owner's portfolio plan. Follow them for every change.

1. **Plan limits.** No paid API. Any AI model inside the project must be a local Ollama model behind a swappable setting. No paid services.
2. **Data.** Public or made-up data only. Nothing from the owner's employer, no client or retailer names, no copied work code, selectors or lists.
3. **Language.** Plain words in every README and write-up. No em dashes. Explain any jargon once.
4. **Evidence.** Keep NOTES.md dated. Save a screenshot at every milestone. Run code and show real output before claiming anything works. Record failures honestly.
5. **Numbers.** Report only numbers produced by runs in this repo. Never invent a result or a percentage.
6. **Publishing.** Don't push, publish, or change the portfolio site until the owner says so.
7. **Story.** Sitescout is a public re-creation of ideas proven at work in Undercut, applied to a different domain. Git history shows the dates; never describe it as having come first unless that is true.
8. **Finish.** End with a two-chapter case study. Chapter 1 (at work) stays as placeholders for the owner.
